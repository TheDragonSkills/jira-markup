Lists

Lists allow you to present information as a series of ordered items.

Notation Comment 
* some
* bullet
** indented
** bullets
* points

A bulleted list (must be in first column). Use more (**) for deeper indentations.

Example:

  • some
  • bullet
    • indented
    • bullets
  • points
 
- different
- bullet
- types

A list item (with -), several lines create a single list.

Example:

  • different
  • bullet
  • types
 
# a
# numbered

# list

A numbered list (must be in first column). Use more (##, ###) for deeper indentations.

Example:

  1. a
  2. numbered
  3. list
 
# a
# numbered
#* with
#* nested
#* bullet
# list

* a
* bulleted
*# with
*# nested
*# numbered
* list

You can even go with any kind of mixed nested lists

Example:

  1. a
  2. numbered
    • with
    • nested
    • bullet
  3. list

Example:

  • a
  • bulleted
    1. with
    2. nested
    3. numbered
  • list
